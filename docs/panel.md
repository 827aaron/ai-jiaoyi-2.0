# 面板（jiaoyi panel）

局域网网页，独立进程。主循环 `jiaoyi run` 停着也能打开（灯会全红，数据是落盘的最后状态）。

```bash
make install                 # 新增依赖 fastapi / uvicorn
.venv/bin/jiaoyi panel       # 默认 0.0.0.0:8090
```

Mac mini 本机打开 http://localhost:8090 ；手机 / 其他电脑用 Mac mini 的局域网地址
（`ipconfig getifaddr en0` 查），例如 http://192.168.1.20:8090 。

- 只接受本机和局域网地址（私有网段、回环、链路本地）来的请求，公网地址一律 403。
  不要在路由器上把 8090 转发出去。
- 读 `data/` 下的决策日志、模块状态、执行层账本、熔断状态、封禁名单；资金和浮盈浮亏从
  hummingbot-api（`127.0.0.1:8000`，密码取钥匙串里的 `HUMMINGBOT_API_PASSWORD`）查。
  hummingbot 连不上时总资产退回账本里最后一次权益，并在“总资产”旁注明。
- 不导入执行层（唯一例外：用 `jiaoyi.execution.live_gate` 校验面板密码）、不下单
  （`tests/test_panel.py` 里有结构测试）。密钥的值不进面板的数据和接口：设置页只显示配没配，
  由 `jiaoyi panel` 启动时查好传入。
- 已做：总览（作战卡 / 信号 / 持仓都能点开）、持仓（K 线 + 止盈 / 开仓 / 止损 / 保命线、每一步记录）、团队、
  历史（今天 / 7 天 / 30 天、资金曲线、按信号类型、被拒信号、导出 CSV）、资金（账户数字全部从币安账户实时拉，不能手填）、
  选币（读 data/symbol_pool.json）、设置（涨跌颜色可切换，存在本机浏览器）。

## 写操作

面板自己不下单，也不碰交易所：按钮只是往 `data/panel_commands/` 写一条指令（有效期 60 秒），
主循环每秒取一次去执行，结果写到 `done/<id>.json`，页面上等着显示“已执行 / 被拒 / 过期”。
主循环没在跑时指令会过期，什么都不会发生。

| 按钮 | 在哪 | 要密码 |
|---|---|---|
| 暂停开新仓 | 页头 | 不要（收手的动作越快越好），弹窗确认 |
| 恢复开新仓 | 页头（暂停中才出现） | 要 |
| 全部平仓 | 页头 | 不要，弹窗确认；**会先自动暂停开新仓，恢复要另外点“恢复开新仓”** |
| 平仓（单笔） | 持仓页每行 | 不要，弹窗确认 |
| 重新开会出卡 | 总览作战卡 | 不要 |
| 解封（禁开新仓的币） | 选币页 | 要 |
| 改硬上限、分组上限、运行开关、快环门槛 | 设置页 | 要 |

- 面板密码就是 `jiaoyi set-panel-password` 设的那个（和切实盘同一个）。连错 5 次锁 15 分钟，
  命令行和面板共用一份计数，重启不重置。
- 改配置：先按契约整份校验，不合格不写；写前在同目录留 `*.bak-时间` 备份，
  每项改动记一行 `data/config_changes.jsonl`。主循环不热加载，**重启 `jiaoyi run` 后生效**；
  没重启前总览会提示“配置已改、未生效”（对比 `data/runtime.json` 里的配置指纹）。
  模式（paper / testnet / live）、data_dir、模拟环境、Jev 通道和模型版本不在网页上改。
- `paused.json` 读不出时主循环按“已暂停”处理，总览显示“暂停（状态文件损坏）”。
- 安全：只认局域网来源 IP；Host 头必须是局域网 IP、localhost、`*.local` 或 `--allow-host` 给的名字
  （防 DNS 重绑定）；POST 要 `Origin` 与 Host 一致并带 `X-Jiaoyi-Panel: 1` 头（防别的网站代发）。
- 持仓页 K 线取币安 U 本位公开接口（不需要 key，只用于画图）。图表库 TradingView Lightweight Charts 4.2.0
  （Apache-2.0）放在 `static/lib/`，不依赖外网 CDN。
- 换皮只改 `src/jiaoyi/panel/static/theme.css`（颜色、字体、圆角、阴影令牌）。涨跌色默认绿涨红跌。

## 总览口径

| 项 | 来源 |
|---|---|
| 状态灯 | `module_status.json` 每个角色最新心跳；超过 120 秒没更新算掉线；没心跳 = 未接入（空心） |
| 总资产 | hummingbot USDT 钱包余额 + 未实现盈亏（同执行层口径） |
| 今日盈亏 / 离熔断 | 日初权益优先取 `risk_state.json`（保镖同口径），其次 `positions.json` 的 `day_start` |
| 敞口 | 未结束持仓的名义价值合计 ÷ 总资产 |
| 作战卡 | 今天最新一条军师出卡记录 + 各标的最新会议结论 |
| 信号与决策流 | 拍板、保镖、执行、管家 / 巡逻兵平仓；哨兵只计数 |
| 告警 | 决策日志里的出错、对账补救、下架封禁（告警本身直接推 Telegram，不单独落盘） |
