# 面板（jiaoyi panel）

局域网网页，独立进程。主循环 `jiaoyi run` 停着也能打开（灯会全红，数据是落盘的最后状态）。

```bash
make install                 # 新增依赖 fastapi / uvicorn
.venv/bin/jiaoyi panel       # 默认 0.0.0.0:8090
```

Mac mini 本机打开 http://localhost:8090 ；手机 / 其他电脑用 Mac mini 的局域网地址
（`ipconfig getifaddr en0` 查），例如 http://192.168.1.20:8090 。

- 只接受本机和局域网地址（私有网段、回环、链路本地）来的请求，公网地址一律 403。
  不要在路由器上把 8090 转发出去。
- 读 `data/` 下的决策日志、模块状态、执行层账本、熔断状态、封禁名单；资金和浮盈浮亏从
  hummingbot-api（`127.0.0.1:8000`，密码取钥匙串里的 `HUMMINGBOT_API_PASSWORD`）查。
  hummingbot 连不上时总资产退回账本里最后一次权益，并在“总资产”旁注明。
- 不导入执行层（唯一例外：用 `jiaoyi.execution.live_gate` 校验面板密码）、不下单
  （`tests/test_panel.py` 里有结构测试）。密钥的值不进面板的数据和接口：设置页只显示配没配，
  由 `jiaoyi panel` 启动时查好传入。首次设置向导能**写**密钥，但同样只写不读（见下）。
- 已做：总览（作战卡 / 信号 / 持仓都能点开）、持仓（K 线 + 止盈 / 开仓 / 止损 / 保命线、每一步记录）、团队、
  历史（今天 / 7 天 / 30 天、资金曲线、按信号类型、被拒信号、导出 CSV）、资金（账户数字全部从币安账户实时拉，不能手填）、
  选币（读 data/symbol_pool.json）、设置（涨跌颜色可切换，存在本机浏览器）。

## 开会过程

慢环开会时按阶段写 `data/meeting_live/<SYMBOL>.json`（分析师报告 → 多空辩论 → 交易员计划 → 风控辩论 → 结论；
字段见 docs/slow.md），一个币一个文件，会开完留着当“上一场会”。面板只读：
`GET /api/meeting/<SYMBOL>`（币名过白名单，没有就 404），团队页选「军师团」时列出每个币最近一场会
（正在开的在前，标着正在开却 15 分钟没更新的显示“中断了”）；作战卡每个币下面有「看这个币的开会过程」。
弹窗里正在开的会每 4 秒刷新，展开的发言保持展开；单条发言超过 8000 字截断。
总盘会（看大盘、挑哪些币上会）写 `data/meeting_live/_MARKET.json`，同一格式；团队页列表里固定排第一，
还没有文件时也占一行（点开说“还没有总盘会记录”），弹窗里不画五步进度条。

## 团队页的模块状态

每张角色卡第一行是一句明确的状态（Aaron 2026-10-23：不许写“A 或 B”这种猜测），由 `pages.role_state` 给出：
未启用（runtime.json 的 `stub_roles` 里，或模块自己报 disabled）/ 主程序没在运行 / 等待首次运行 /
正常（上次 hh:mm）/ 降级运行（上次 hh:mm）/ 失败：原因 / 无心跳超过 N 分钟（最后 hh:mm）。
第二行是模块自己报的今日要点（报了上次 / 下次 / 币数的定时任务不再重复显示）。

团队页上半部是流程图（设计稿 design/team-flow，`app.js` 的 `TF_POS` / `TF_EDGES`）：三条泳道
① 准备作战卡 ② 发现信号 → 下单 ③ 看着持仓，节点固定坐标，画布 1180×570 按宽度缩放，≤700px 改按泳道竖排。
① 是 选币 →（候选池）→ 总盘会 →（上会名单）→ 军师团 → 作战卡；总盘会另把要盯的币给盘口员，盘口员拉 K 线给预测员。总盘会节点读 `meeting_live/_MARKET.json`（`TeamPage.market`），点开看会议过程。
每个节点一个点 = `RoleCard.progress`（`pages._progress`）= 本轮流程走到哪，不看心跳：出错（灯红）>
正在做（`doing` 非空：开会中 / 刚刚 / 盯着信号 / 盯着行情 / 盯着持仓）> 这一轮做完 > 等待。
① 选币、军师团、预测员今天跑过 = 做完；盘口员、哨兵心跳正常 = 一直在盯（蓝）。
② 拍板人、保镖、执行器只跟本轮（最新一张作战卡发出之后）最新一个 signal_id 的决策链：链上有记录的 = 做完，其余 = 等待。
③ 管家、巡逻兵、对账员、保命止损有持仓 = 正在做，没持仓 = 等待；报警员今天推过 = 做完。
预测员按需模式（`[predictor] mode = on_demand`）时，卡片写「只算作战卡上的 N 个币」（加不在卡上的持仓币）。
心跳好坏单独放在节点右上角的角标（心跳正常 / 等待首次运行 / 降级运行 / 无心跳 / 失败 / 未启用），鼠标悬停看完整状态。
连线颜色跟终点节点，正在做的蓝色虚线流动；
图例右边「现在走到」按流程顺序说最多两处（盯持仓放最后）。告警不连线，看门狗画成外圈虚线框。

## 资金页的净盈亏

「扣掉所有成本，净赚多少」按 今天 / 近 7 天 / 累计 列 交易盈亏、手续费、资金费、AI 费、净盈亏
（净 = 交易 + 手续费 + 资金费 − AI 费，不含浮盈浮亏）。前三项读 `data/income_daily.json`
（主程序每 5 分钟拉币安收入流水按当地日汇总：`{"tz", "updated_at", "since", "days": {"YYYY-MM-DD":
{"realized_pnl", "commission", "funding_fee"}}}`，币安原始正负号）；文件没有时退回账本，资金费显示“—”。
AI 费按决策记录的 `cost_usd`，1 美元按 1 U 算。

「AI 费用详情」（`pages.build_ai_costs`，`/api/funds?ai=today|7d|all`）把军师团、拍板人、持仓管家、预测员的
决策记录里花了钱或出错的每一条列出来：时间、谁（军师团 · 某币会议 / 总盘会 / Jev 拍板 / Jev 持仓审查）、币、
花费、tokens（读 `output.usage.input_tokens + output_tokens`，没写就显示“没记”）、结果（ERROR 且摘要含“超时” = 超时，
其余 ERROR = 失败）。总盘会花费在出卡记录（`card_id` + ACTION）的 `cost_usd` 里；`output.cost_estimated` 为真的标「估」。
顶部按 军师团 / 总盘会 / Jev 小计；明细最多列最近 300 条。

## 首次设置（/setup）

换一台 Mac 不用敲命令：`bootstrap_mac.sh` 装完会在本机打开 http://127.0.0.1:8090/setup 。
`config/risk.toml`、`app.toml` 不存在时 `jiaoyi panel` 会先从 `*.example.toml` 复制一份。
本机打开首页时，面板密码或必填密钥没配齐会自动跳到这里。

1. **面板密码**：只能在还没设过时设；改密码仍用 `jiaoyi set-panel-password`（要旧密码）。
2. **密钥**：必填 OpenRouter、币安 Demo key / secret、Telegram token / chat id、hummingbot-api 密码；
   可选币安主网、Jev / DeepSeek 直连、FRED。写进 macOS 钥匙串（值走 `security -i` 的标准输入，
   不出现在进程参数里，写完读回核对）。页面只显示“已配 / 未配”，从不回显；留空 = 不改。
   新的 hummingbot-api 密码不用重启面板就生效。
3. **基本配置**：开会间隔、最长持仓、拍板人通道、军师团通道、军师团日花费上限。运行方式不在这改（实盘走 go-live）。
4. **自检**：配置文件、hummingbot-api 连通和余额、给 Telegram 发一条测试消息。

安全：整个向导的写接口只认**本机**请求：来源 IP 是回环，且地址栏是 localhost / 127.0.0.1。
用局域网 IP 打开（哪怕就在 Mac 上）只显示“请在 Mac 本机打开”。第 2–4 步都要面板密码（错 5 次锁 15 分钟），
POST 照样过 Host 白名单和 Origin / `X-Jiaoyi-Panel` 校验。不是 macOS（没有 `security`）时密钥只能看不能写。

## 写操作

面板自己不下单，也不碰交易所：按钮只是往 `data/panel_commands/` 写一条指令（有效期 60 秒），
主循环每秒取一次去执行，结果写到 `done/<id>.json`，页面上等着显示“已执行 / 被拒 / 过期”。
主循环没在跑时指令会过期，什么都不会发生。

| 按钮 | 在哪 | 要密码 |
|---|---|---|
| 暂停开新仓 | 页头 | 不要（收手的动作越快越好），弹窗确认 |
| 恢复开新仓 | 页头（暂停中才出现） | 要 |
| 全部平仓 | 页头 | 不要，弹窗确认；**会先自动暂停开新仓，恢复要另外点“恢复开新仓”** |
| 平仓（单笔） | 持仓页每行 | 不要，弹窗确认 |
| 重新开会出卡 | 总览作战卡 | 不要 |
| 重启生效 / 重启主程序 | “配置已改、未生效”横幅；设置页「运行」卡片常显（有待生效改动时高亮为「重启生效」） | 要 |
| 解封（禁开新仓的币） | 选币页 | 要 |
| 固定 / 手动加入 / 取消拉黑（`pin_symbol` / `add_symbol` / `unblacklist_symbol`） | 选币页每行按钮；顶部「手动加币」输入框 | 要 |
| 拉黑 / 取消固定 / 取消手动加入（`blacklist_symbol` / `unpin_symbol` / `remove_symbol`） | 选币页每行按钮（拉黑 / 取消固定 / 移除） | 不要（只会更保守） |
| 类别开关 / 每类进池上限（`set_category` / `set_category_cap`，值可写 default 清掉） | 选币页「按类别选币」：开 / 关、「改上限」、「改回 slow.toml」；每格标出值来自 选币页设的 > slow.toml `[screener.categories]` > 默认 | 要（同一条指令可能放宽也可能收紧） |
| 改硬上限、分组上限、运行开关、快环门槛（含 ATR 周期 / 倍数）、预测员运行方式、军师团节奏（slow.toml `[schedule]`）、选币规则（slow.toml `[screener]`） | 设置页：点开某一项 →「修改」，一次改一项（有推荐值的还有「用推荐值」） | 要 |

- 设置页布局（v2）：首屏是待生效横幅（列出主程序这次启动后改的项）、「运行」（模式 / 主程序 / 开新仓 / 开会间隔 / 单笔最长持仓）、
  「风险」（每笔风险、日亏熔断、最大杠杆三项）；其余在「高级」的五个标签里（风控细项 / 执行 / 军师团 / 密钥 / 显示，
  记住上次选的）。键到分组的对照在 `app.js` 的 `ADV`；契约新加的键没列进去时自动落到对应标签的「其他」组。
- 「军师团」标签的「选币规则」三组（门槛 / 打分 / 权重）改的是 slow.toml `[screener]`：成交额、深度、上线天数、
  24 小时波动下限 / 上限有推荐值（2000 万 / 10 万 / 7 天 / 1.5% / 30%），波动 0 = 不设；比推荐冒险的只标黄、
  组里列 `ScreenerSection.cautions(硬上限最大价差)` 的提示，不拦。只有下限 ≥ 上限、五项权重全 0 才存不进去。
- 同一标签的「分档交易」组改 slow.toml `[screener.tiers]`（面板段名 `tiers`）：开关、头部几个、中部几个、
  中部每天挑几个、中部仓位最大档（小 / 中 / 大）；「美股类别」组是 `[screener]` 的 `us_events` / `us_open_bonus`。
- 「开会间隔」= `meeting_interval` 7 档（15 分钟 … 24 小时，默认 1 小时），一键切换，要面板密码、重启生效；作战卡有效期 = 间隔 + 20 分钟。
- 「单笔最长持仓」= `hold`：第一个按钮「跟开会档位（N）」= app.toml 里不写 hold，按 `profiles.RECOMMENDED_HOLD` 跟开会间隔走；
  点 30 分钟 / 1 / 2 / 4 小时 = 写死这一档，行内标「自定义」（30 分钟只在模拟盘可点）。自定义且和开会档位的推荐不一样时只提醒，不拦。
  `fast_loop.time_limit_s` 写死的话会压过 hold，切持仓档时一起删掉。止损 / 止盈 / ATR 周期 / 拍板门槛等 fast_loop 键标「跟最长持仓走」，
  写死项的默认值按 `profiles.defaults(meeting_interval, 段, hold)` 算，和主程序读配置同一口径。
  「改 K 线周期」单独改 `atr_period_min`；选项标「适合最长持仓 X」（5 分 ≤30 分钟 / 15 分 1–2 小时推荐 / 30 分 2–4 小时 / 60 分 4 小时以上），
  和当前最长持仓对不上时行内和弹窗里都提醒，不拦。`/api/settings` 的 profile 卡片带 `hold`、`hold_custom`、`hold_choices`、
  `hold_paper_only`、`hold_recommended`、`hold_specs`（每档秒数和 ATR 周期）。
  切换弹窗列出配置文件里写死、会压过新档位默认的项（文件值 → 档位默认值），默认勾选“清掉这些写死项，完全按档位走”：
  删掉 app.toml / slow.toml 里所有档位键的行（各留 `.bak-<时间>` 备份，记进 config_changes.jsonl），再切档位。
  档位卡片里也有同一个按钮（`POST /api/settings/clear-profile-pins`，要面板密码）。
  档位键在网页上填了值就会一直覆盖档位默认（标“已覆盖档位默认”），点“恢复档位默认”删掉那一行即可跟档位走。
- **重启生效**：主程序先停开新仓（不落盘暂停，重启后保持原来的暂停状态），等在途开仓和平仓做完，
  限时收尾（20 秒），在进程退出前一刻写回执，然后直接结束进程（`os._exit(0)`；军师团开会跑在工作线程里，
  正常退出会被它拖住十几分钟；收尾卡住 45 秒也强制退出），由 launchd（`com.jiaoyi.run`，KeepAlive）拉起。
  页面显示“重启中…”，直到 `data/runtime.json` 的启动时间变了、心跳恢复，再按配置指纹报“已按新配置重启”。
  万一回执没写成，新进程看到比自己启动还早的 restart 指令只补回执，不会再重启一次。
- 面板每次请求都看配置文件的修改时间，改了就重读（离熔断、上限等马上按新值显示，不用重启面板）；读坏了沿用上一份。
  会拒绝的情况：不是 launchd 托管（手动 `jiaoyi run` 退了就没人拉起）、新配置校验不过（免得起不来反复崩）、
  平仓 60 秒没做完（被拒后照常开仓）。管家、巡逻兵、对账在等待期间照常跑。
- 面板密码就是 `jiaoyi set-panel-password` 设的那个（和切实盘同一个）。连错 5 次锁 15 分钟，
  命令行和面板共用一份计数，重启不重置。
- 改配置：先按契约整份校验，不合格不写；写前在同目录留 `*.bak-时间` 备份，
  每项改动记一行 `data/config_changes.jsonl`。主循环不热加载，**点“重启生效”（或手动重启 `jiaoyi run`）后生效**；
  没重启前总览会提示“配置已改、未生效”（对比 `data/runtime.json` 里的配置指纹）。
  模式（paper / testnet / live）、data_dir、模拟环境、Jev 通道和模型版本不在网页上改。
- 面板进程启动时记下代码指纹（`jiaoyi` 包源码和静态文件的修改时间）；`git pull` 后没重启面板，顶部会提示
  “面板版本与代码不一致”。任何页面接口 5 秒没回或报错，都会显示错误原因，不会一直“正在读取…”。
- `paused.json` 读不出时主循环按“已暂停”处理，总览显示“暂停（状态文件损坏）”。
- `pool_overrides.json`（选币页的固定 / 拉黑 / 手动加入）读不出时，启动即暂停开新仓（拉黑清单没生效），
  总览显示原因，面板“恢复开新仓”会被拒；修好或删掉文件后重启主程序自动恢复。人工暂停不受影响。
- 安全：只认局域网来源 IP；Host 头必须是局域网 IP、localhost、`*.local` 或 `--allow-host` 给的名字
  （防 DNS 重绑定）；POST 要 `Origin` 与 Host 一致并带 `X-Jiaoyi-Panel: 1` 头（防别的网站代发）。
- 面板走明文 HTTP，密码在局域网里是明文传的：家里的网络可以接受，**不要从外网直接访问**；
  以后要在外面用，先上 HTTPS 或 VPN（例如 Tailscale，再用 `--allow-host` 放行它的名字）。
- 配置备份 `config/*.bak-*` 已在 `.gitignore` 里（里面有你的真实硬上限，不进仓库）。
- 网页改了硬上限后，实盘要重新 go-live 的保护在 #43 里；M4 上实盘前 #43 必须先合并。
- 持仓页 K 线取币安 U 本位公开接口（不需要 key，只用于画图）。图表库 TradingView Lightweight Charts 4.2.0
  （Apache-2.0）放在 `static/lib/`，不依赖外网 CDN。
- 换皮只改 `src/jiaoyi/panel/static/theme.css`（颜色、字体、圆角、阴影令牌）。涨跌色默认绿涨红跌。

## 总览口径

| 项 | 来源 |
|---|---|
| 状态灯 | `module_status.json` 每个角色最新心跳；超过 120 秒没更新算掉线；没上报过 = 空心（主程序在跑：等待第一次上报；不在跑：主程序没在运行） |
| 总资产 | hummingbot USDT 钱包余额 + 未实现盈亏（同执行层口径） |
| 今日盈亏 / 离熔断 | 日初权益优先取 `risk_state.json`（保镖同口径），其次 `positions.json` 的 `day_start` |
| 敞口 | 未结束持仓的名义价值合计 ÷ 总资产 |
| 作战卡 | 今天最新一条军师出卡记录 + 各标的最新会议结论 |
